# Guardian- (نايت / نايتمير)

بوت تيليجرام متكامل لحماية المجموعات، إدارة الأقفال، ومساعد ذكي تفاعلي مبني بواسطة **Pyrogram** وقاعدة بيانات **SQLite** ومدعوم بنموذج **Google Gemini**.

---

## المميزات الرئيسية 🚀

- **أمر المساعدة الشامل**: أمر `/help` أو `مساعدة` متوفر في الخاص والمجموعات لعرض كافة إمكانيات وأوامر البوت بسهولة.
- **نظام أقفال شامل للمجموعات**: حماية كاملة من الصور، الفيديو، الروابط، المعرفات، التوجيه، البوتات، الستكرات، والمزيد.
- **تنبيه وحذف فوري**: عند إرسال أي محتوى مقفول، يقوم البوت بحذف الرسالة فوراً وإرسال تنبيه مؤقت يُحذف تلقائياً بعد 5 ثوانٍ للحفاظ على نظافة الدردشة.
- **تخزين دائم (SQLite)**: حفظ إعدادات الأقفال والمستخدمين المكتومين والمحظورين في قاعدة بيانات `guardian.db`.
- **فلترة الكلمات البذيئة بالذكاء الاصطناعي**: فحص الرسائل غير المتزامن (Non-blocking) عبر Google Gemini وحذف المحتوى المسيء وكتم الفاعل فوراً دون تعطيل سير المحادثات.
- **مساعد ذكي تفاعلي**: الرد بالذكاء الاصطناعي بشخصية مهذبة عند مناداة البوت باسمه (نايت، نايتي، nightmare، إلخ).
- **دعم مكتبات Gemini الحديثة والقديمة**: متوافق مع حزمة Google GenAI الحديثة (`google-genai`) مع استمرار دعم `google-generativeai` القديمة والتنقل الذكي بين مفاتيح API في حال انتهاء الحصة (Quota Failover).

| الأمر | النطاق | الوظيفة |
| :--- | :--- | :--- |

## أوامر التحكم بالأقفال 🛡️

> **ملاحظة**: أوامر الأقفال متاحة فقط للمشرفين والمالك في المجموعات.

| الأمر | الوظيفة |
| :--- | :--- |
| `الاقفال` أو `الأقفال` | عرض لوحة تفاعلية بحالة جميع أقفال المجموعة (🔒 مقفول / 🔓 مفتوح) |
| `قفل الكل` | قفل جميع الميديا والمحادثة بضغطة واحدة |
| `فتح الكل` | فتح جميع الأقفال وإتاحة المحادثة بالكامل |
| `قفل الشات` / `فتح الشات` | قفل أو فتح الدردشة الكتابية للأعضاء |
| `قفل الصور` / `فتح الصور` | قفل أو فتح إرسال الصور |
| `قفل الفيديو` / `فتح الفيديو` | قفل أو فتح مقاطع الفيديو والفيديو نوت |
| `قفل المتحركات` / `فتح المتحركات` | قفل أو فتح الصور المتحركة (GIFs) |
| `قفل الستكرات` / `فتح الستكرات` | قفل أو فتح الملصقات |
| `قفل الصوت` / `فتح الصوت` | قفل أو فتح الرسائل الصوتية والبصمات والملفات الصوتية |
| `قفل التوجيه` / `فتح التوجيه` | قفل أو فتح إعادة التوجيه من قنوات أو محادثات أخرى |
| `قفل الروابط` / `فتح الروابط` | قفل أو فتح الروابط والمواقع (t.me، https، إلخ) |
| `قفل المعرفات` / `فتح المعرفات` | قفل أو فتح المعرفات (@username) |
| `قفل التاك` / `فتح التاك` | قفل أو فتح المنشن التفاعلي والتاك |
| `قفل الملفات` / `فتح الملفات` | قفل أو فتح المستندات والملفات |
| `قفل جهات الاتصال` / `فتح جهات الاتصال` | قفل أو فتح مشاركة جهات الاتصال |

| `قفل البوتات` / `فتح البوتات` | طرد أي بوت يُضاف إلى المجموعة تلقائياً |

## أوامر الإشراف بالرد (Reply) 👮‍♂️

| الأمر | الوظيفة |
| :--- | :--- |
| `كتم` (أو `كتم 120`) | كتم العضو (افتراضياً 60 دقيقة أو تحديد المدة بالدقائق) |
| `طرد` | حظر وطرد العضو من المجموعة |
| `رفع الكتم` | إلغاء الكتم عن العضو فوراً |
| `رفع الحظر` | إلغاء الحظر عن العضو |
| `/Arise` | عرض قائمة الأعضاء المكتومين والمحظورين مع المدة المتبقية |

## التشغيل ⚙️

1. قم بتثبيت المتطلبات:
   ```bash
   pip install -r requirements.txt
   ```
2. تأكد من إعداد ملف `.env`:
   ```env
   api_id=YOUR_API_ID
   api_hash=YOUR_API_HASH
   BOT_TOKEN=YOUR_BOT_TOKEN
   # يمكنك استخدام المفتاح القياسي أو عدة مفاتيح للتبديل التلقائي
   GEMINI_API_KEY=YOUR_GEMINI_KEY
   GEMINI_API_KEY_1=YOUR_GEMINI_KEY_1
   GEMINI_API_KEY_2=YOUR_GEMINI_KEY_2
   GEMINI_API_KEY_3=YOUR_GEMINI_KEY_3
   ```
3. تشغيل البوت:
   ```bash
   python main.py
   ```
